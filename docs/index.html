Introduction

Cellmap is an app intended to enable machine learning researchers to visualize the prediction results over the input images to gain a better understanding towards the model and potential improvement. By uploading the prediction in json format as well as the corresponding image(s), the visualizations will be then displayed in the canvas(es) and other supportive panels.
